# 04. 화면 설계

디자인 원칙: 글라스 HUD 느낌 = **순수 검정 배경 + 단색(기본 녹색 #39FF7A) 글자 + 장식 최소**. Even의 로고·아이콘·레이아웃은 쓰지 않는다.

## 화면 1. 메인(HUD)
```
┌───────────────────────────────┐
│ ● 듣는 중  EN → KO   ⚙ ☰     │  ← 상단 바(작게, 회색). 상태점: 회색=대기, 녹색=듣는 중, 빨강=오류
│                               │
│   (원문, 작게·흐리게)           │  showOriginal
│   Where is the trauma bay?    │
│   (번역, 크게)                  │
│   외상 처치실이 어디죠?          │
│   (중간결과는 50% 밝기)          │  showInterim
│                               │
│  p50 첫글자 420ms · 확정 890ms │  ← latencyOverlay 켰을 때만
├───────────────────────────────┤
│  [모드: 번역|대화|받아쓰기]      │  ← 하단 컨트롤
│        ( ● 시작 / ■ 정지 )      │  큰 원형 버튼
│  [KO ▼]  ⇄  [EN ▼]            │  언어 선택(4개), ⇄ 맞바꾸기
└───────────────────────────────┘
```
- 자막 영역은 최근 `hud.maxLines` 줄만 보이고 위로 밀려 올라감(자동 스크롤, 애니메이션 없이 즉시).
- 화면 탭 → 컨트롤 숨김/표시(몰입 모드). 
- hud.mirror: 자막 영역만 `transform: scaleX(-1)`.

## 화면 2. 대화 모드
```
┌───────────────────────────────┐
│   (180° 회전) 상대방 언어 자막    │  ← 테이블 맞은편 상대가 읽음
├──────── 상태/언어 ─────────────┤
│   내 언어 자막                   │
│        ( ● / ■ )               │
└───────────────────────────────┘
```
- Web Speech 엔진일 때는 가운데에 [내가 말함] [상대가 말함] 토글 버튼.

## 화면 3. 설정 (⚙, 전체 화면 패널)
섹션 순서와 항목은 02_requirements.md §3 표와 동일:
1. 언어·모드  2. 엔진·키(키 입력란은 password 타입, "기기에만 저장" 문구)  3. 표시(HUD)  4. 정확도(정밀 번역, 모델, 용어집 편집)  5. 기능 켜기/끄기(화자 구분, 기록, 지연 표시, 화면 꺼짐 방지, TTS…)  6. 개인정보 고지·기록 전체 삭제.
- v2 기능 토글은 "준비 중" 배지와 함께 비활성 표시.

## 화면 4. 기록 (☰)
- 세션 목록(날짜, 언어쌍, 길이) → 상세(원문/번역 2열) → 복사·Markdown 내보내기·삭제.

## 접근성·기타
- 글자 크기 16–64px, 줄 간격 1.3. 
- 첫 실행: 마이크 권한 안내 + 외부 API 전송 고지(의료 정보 주의) 1회.
